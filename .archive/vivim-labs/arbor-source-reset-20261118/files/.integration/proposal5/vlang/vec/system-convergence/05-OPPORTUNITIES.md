**Prioritize P0 before performance migration:** installed SDK crosswalk, deterministic Build, native IR parity, three UI document bridges, Host-owned personal programs, verifier trust roots. Then build useful reactive widget & editing experiences. Only port measured pure compute into Rust when cross-surface performance and resource usage justify it.

Cadence categories distinguish always-on observers, frequent pure execution, user-defined workloads and development/admin builds. None of the frequencies has been measured here.

**Benchmark protocol:** synthetic source corpus and invented personal program fixtures, pinned exact commit/toolchain/OS, warm/cold runs, p50/p95 wall/CPU/RSS/disk/energy, FFI overhead, cache invalidation, failure and rollback. Preserve JS/TS fallback when native substitution underperforms or cannot run.
