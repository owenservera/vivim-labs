## Experimental programming model
Every trial: hypothesis -> immutable program -> independent workload/oracle -> deterministic paired run plan -> isolated execution -> observed receipts -> qualification -> comparison -> staged policy candidate -> independent holdout -> optional Host-approved promotion -> regression watch/rollback. Baseline and challenger use the same task, source, budget, seed and fault milestones; randomized ordering mitigates but does not remove provider/time effects. No learning from holdout inputs, no cross-arm state leakage, no future evidence in scheduler. Each policy revision is pinned and active runs stay pinned. Never auto-increase budgets. All observations unknown unless measured; failed/late/uncertain requests cost resources. A successful process is not a verified task. Reuse existing kernel oracle (typed exact/digest/predicate), private custody and evidence, do not build a second acceptance authority. For nondeterministic source interpretation, independently compare exact source spans and semantic counterexamples, not model self-scores.
## Stress and tuning matrix (planned, not run)
T01 native correctness: exact arithmetic/typed graph, malformed and cyclic input, missing refs, stale output.
T02 journal/storage: torn writes, corrupt history, concurrent writers, deleted suffix, readback/reopen; anchored history; verify no lost committed artifacts.
T03 population: 1/4/10 active slots where supported, 1/10/60/256 logical agents; dormant inference zero, fairness and no double lease. Existing native qualification supports up to four slots, ten is live adapter target only after containment.
T04 recovery: interrupt owned worker/controller at verified milestones; actual process exit observation, restart, cancellation, stale generation rejection and zero duplicates.
T05 adapter: pinned binary/account/model, expired/replayed request, unknown/late result, wrong model identity, zero vs unknown cost, malformed/truncated/out-of-order output; no blind retry.
T06 communication: incremental cursor, gaps, dedup, slow consumer, steering acknowledgement, interrupted delivery, cross-lane messaging, no lost context.
T07 scheduling: compare FIFO/critical path/uncertainty/cost policies; identical workload, measure verified yield, wait, starvation and latency.
T08 routing: free provider/model changes, quota exhaustion/429, availability and latency, reservation overruns, unknown settlements; use existing routing trial guard. No paid fallback.
T09 context: fixed vs relevance/dependency-selected bundles; measure context bytes, token use, correctness and omitted mandatory facts.
T10 classes: generic vs learned specialized contracts; same inputs, independent semantic fixtures; class regression/rollback.
T11 learning/reuse: cold, repeated, perturbed and disjoint holdouts; zero inference on qualified unchanged deterministic procedure, compare amortized acquisition+reuse cost and output correctness.
T12 isolation: session/agent/goal/intelligence comparative arms with actual enforced custody and identical seeds/fault schedule; no leaked knowledge.
T13 VIVIM workpiece: OpenCode existing source -> canonical semantic atom -> typed route proposal -> independent verification -> registry admission under Host, repeat with another vendor. Separate proposal counts, semantic coverage, live receipts and deterministic reuse.
T14 endurance: progressively longer real wall time, repeated fault schedule and bounded resource budgets; programmable duration thresholds (e.g. 36h/72h only if requested/approved), do not claim simulated time.
T15 owner controls: live status, pause/stop, revoke, approve, modify future policy, verify no dispatch after revocation; preserve outstanding uncertainty.
T16 capacity: storage/index growth, large source packets, event bursts, recovery latency, CPU/memory/disk, measured throughput; resource envelope must be observed, not assumed.

## Known limitations
No new native build, test run, model invocation or cost verified; previous runtime build is historical. Actual installed OpenCode event identity/usage schema is not qualified. Adapter checks trusted reference presence, not validity of external enforcement; live_enabled must remain false until Host verifies it. The capture parser's step_finish and exit do not prove provider settlement. Experiment compiler is intentionally pure and not yet wired to scheduler, oracle custody or actual execution. Comparison uses conservative per-pair non-regression on requests/tokens/wall, so may reject legitimate tradeoffs; more programmable objective/metric definitions are future work. No 50-gate tracker changes and no claimed percentage gain.
