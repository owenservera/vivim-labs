## Facts that matter
- HQ and TierFlow both use SQLite but with **different explicit durability** (`NORMAL` rebuildable dev index versus `FULL` UI revision history). Uniform PRAGMA tuning would be dangerous.
- Rust has built-in manual benchmark files [`bench_vertical.rs`](https://github.com/owenservera/ARBOR/blob/98f15e327957956ec94189772d5e5813e7b6b07b/native/hqkg/tests/bench_vertical.rs) and [`benchmark_typed_dag.rs`](https://github.com/owenservera/ARBOR/blob/98f15e327957956ec94189772d5e5813e7b6b07b/native/hqkg/tests/benchmark_typed_dag.rs). They are **ignored by default**, and their source is not proof they ran in this inspection.
- `Cargo.toml` root includes `native/hqkg`, `core/programmability`, `src-tauri`; no assertion is made that root build/lock closure succeeds today.
- A module's presence does not prove it is live, always-running, or the canonical product entrypoint. Frequency classes below are primary **load hypotheses**; actual caller instrumentation is needed.

## Do not misdiagnose as optimization debt
Authorization failures, invalid receipts, privacy leakage, silent data loss, inaccurate clock order and non-recoverable writes are **correctness/security blockers**, never acceptable speed-for-safety trade-offs.
