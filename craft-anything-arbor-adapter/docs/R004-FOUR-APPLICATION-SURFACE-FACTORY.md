## Architecture
Craft is initially an external investigation process, not product dependency or another production actor. Capture permitted visible application surfaces with independent investigation browser and user-controlled sign-in. Never clone production cookies/profiles or bypass access restrictions. Use existing VIVIM workstation tools where granted. Do not open private content unnecessarily; private evidence stays local, no raw screenshots, conversations, account identifiers or credentials in Git. Respect application terms and permissions; human-guided/manual observation and public documentation where automated exploration is not permitted. No unattended third-party crawling or effectful exploration. Studio remains sole production browser actuator under Host. No provider APIs. GPUI only product renderer; PWA remote viewport. Rust first for pure compute; MJS compatibility stays until parity.

## Native migration crosswalk (incremental)
1. **Evidence/unknowns first**: Craft crates/evidence/src/{canonical.rs,lib.rs,unknown.rs}; existing Studio integrity, HQKG provenance. Reuse verifier first, then extract pure canonical hashing/coverage/unknown deltas only after license and differential Rust/JS checks (floats, Unicode, nesting, missing/duplicate evidence). Existing importer needs native real-bundle parity; never disable hashing.
2. **Responsive UI atlas**: website_tools.rs (1788 lines) already captures screenshots, rendered HTML where allowed, design tokens, layout outlines, assets, links, forms; clean-room forbids HTML. Current Studio capture/AX/shape observations and Labs importer do not expose complete surface semantics. Harvest pure layout/role normalization and responsive diff; do not copy browser lifecycle or private capture.
3. **Behavior evidence**: browser_tools.rs (2612 lines) supplies page observation, snapshots/pixel comparison, walkthrough/check; use authorized manual or first-party demonstrations. Harvest pure step/state comparison and independent final-state verification into Studio/VLANG, not generic script execution. Current conversation-oriented learning features need broader typed UI objects.
4. **Change detection**: analysis/src/js_compare.rs (677 lines) tiered module matches and route changes; engine/src/tools/compare_tools.rs (976 lines) evidence bundle comparison, change summary, runtime correlation/rebuild claim verification; extract applicable pure matching and coverage algorithms after comparing incumbent Studio identity/graph and existing craft delta. Not all static code techniques fit visible third-party surfaces.
5. **Investigation-to-wiki**: session_tools.rs export and unknown lifecycle, investigation/report tools and js_ledger.rs; adapt evidence-linked findings and unresolved questions to existing HQKG/AutoWiki, not new DB.
6. **Permitted static source analysis later**: js_app/js_trace/js_inventory/api_ops/fingerprint/html; use only owned or specifically authorized code. html.rs is a script/CSP scanner, NOT full accessibility parser. OXC and format dependencies reviewed individually. No private API discovery/replay as product transport.
7. **Retain external**: Craft browser/session/MCP engine, sign-in, platform tooling and standalone UI; do not port credential/profile cloning, consent inbox, second browser owner or arbitrary runtime access. MIT OR Apache-2.0 workspace declaration; inspect file/dependency licenses and notices before copying.
8. **Retire external dependency per capability** after real capture parity, deterministic tests, bounded CPU/RAM, evidence fidelity, exact revision, rollback; not a wholesale port.
