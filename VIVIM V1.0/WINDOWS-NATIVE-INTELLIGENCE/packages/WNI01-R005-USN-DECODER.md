# WNI01 R005 — NTFS USN record decoder and continuity

Implemented [usn.rs](../rust-starter/src/usn.rs): variable-length V2/V3 records, alignment and offset validation, signed USN continuity, version refusal, bounded count/bytes, scope-admitted identities, and no decoded filenames. Unknown/version-4 records require rebaseline rather than silently skipping. All bytes are validated before any admission callback. Only a caller-approved identity predicate may select events. This is the decoder for FSCTL_READ_USN_JOURNAL, not FSCTL_ENUM_USN_DATA and not an authorized volume collector. No volume open, no elevation, no global path reconstruction. Caller must bind volume+journal ID, trusted file identity, scope/grant and baseline transaction. Unknown files discovered by scoped baseline. Use prior non-elevated watcher where journal API not supported/authorized. Rust tests supplied; compile/Windows tests UNRUN.

Primary sources: https://learn.microsoft.com/en-us/windows/win32/fileio/walking-a-buffer-of-change-journal-records ; https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ns-winioctl-usn_record_v2 ; https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ns-winioctl-usn_record_v3 .
