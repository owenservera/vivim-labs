# R023 — optional Windows platform support discovery

Three workstreams: WNI06 App Actions, WNI07 Graphics Capture, WNI10 Windows ML. Isolated typed Windows crate 0.61.3 (already in ARBOR GPUI Cargo.lock). WinRT apartment initialization, documented GraphicsCaptureSession::IsSupported, and ApiInformation::IsTypePresent for named runtime classes. No capture frames, app activation, model load, package registration, provider download, or permission prompt. Type presence is only metadata availability, NOT usable action catalog, hardware acceleration or runtime installation. A framework-specific WinML type may be absent from this process because no Windows App SDK bootstrap was performed; do not equate that with machine-wide absence. Report unknown on API failure. No new mandatory runtime dependency. This is a support probe, not an execution adapter. Native build/run pending.
