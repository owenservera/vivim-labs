# Persistent entities

Independent conceptual entities, not prescribed storage or implementation:

| Entity | Responsibility |
|---|---|
| Goal | What must be accomplished |
| Task | A decomposable unit of work |
| Class | Reprogrammable behavioral capabilities |
| Agent | Allocation of intelligence |
| Context | Knowledge relevant to an operation |
| Artifact | Materialized work and discoveries |
| Evidence | Proof of occurrence or correctness |
