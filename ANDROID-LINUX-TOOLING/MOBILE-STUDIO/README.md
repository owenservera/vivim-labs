# Mobile Studio research — R001
Start with [owner objective](OBJECTIVE.md), [capability catalogue](CAPABILITY-CATALOGUE.json), [architecture](ARCHITECTURE.md), [research and experiment plan](RESEARCH-PLAN.md), and [device evidence](R001-DEVICE-EVIDENCE.md). Labs only: no product migration, second registry or active authorization.

This is an Android-native app capability research program, not merely a Termux tool inventory. The Product SDK remains canonical for Meta-VLANG, typed IR, capability identity, Host effects, receipts and graph projections. The companion should be a thin OS adapter, not an independent renderer or orchestrator. Each capability requires actual permission, target app support, and real device evidence. No root, permission bypass, arbitrary private app access or protected screen capture. No llama.cpp or models in scope.

Sources: Context7 resolved Android Developers (/websites/developer_android), queried package visibility/intents, capture and accessibility, notification and background services. Official references and policy in the research plan. An app installed on the device is not equivalent to an accessible app interface.
