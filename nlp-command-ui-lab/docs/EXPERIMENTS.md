## Proposed evaluation protocol

- 30 novice journeys and 30 power-user journeys; preserve raw expectations and actual compiled output separately.
- Latency percentiles from keystroke to visual response (source-load vs parse vs paint); bound stale requests.
- Precision on command-vs-chat classification; false-positive **effects** are never accepted.
- Coverage: total catalog entries with user-facing icon, English reading, typed menu, executable receipt, undo/recovery metadata; show **unknown** for absent source.
- Traceability: every rendered action ID displays exact owner, version and source evidence; no inferred availability.
- Screenshot supplied by owner is qualitative input for compact icon/field grammar. Do not claim pixel identity or old-run acceptance until component provenance is confirmed.
