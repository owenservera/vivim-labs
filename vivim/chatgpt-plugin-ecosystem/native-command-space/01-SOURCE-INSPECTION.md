**Existing schema boundary:** Current catalog `args` accepts typed **string/enum** fields. Arbitrary deeply nested arrays/graphs, file handles and process session descriptors require a versioned `CommandFrame` IR, adapter and compatibility migration; cannot be deployed by simply dropping 279 JSON records into `action-catalog.v1.json`.

**Baseline counts:** R0=15, R1=15, R2=7, R3=1. Readiness is **source wiring evidence only**, not measured live availability. Distinguish action ID count from phrase coverage.

**Missing product guarantees:** general user filesystem broker, OS process session broker, app/window service, generic document/media adapters, cross-step transaction/compensation, weighted language evaluation. Do not label them implemented based on existing isolated helper files.
