## Exact stages
```ts
function compileCapabilityFacts(input) {
  assertPinned(input.pin); // repo identity, sha, tree, manifest and scope; no moving ref
  assertDigest(verifiedCanonicalOwnerCatalog);
  assertNoUnapprovedPaths(input.files);
  const obs=[]; const diagnostics=[]; const facts=[];
  for(const f of stableSorted(input.files, "path")) {
    if(excludedByCanonicalWalker(f)) { recordExcluded(); continue; }
    if(f.bytes.length>LIMITS.maxFileBytes) { recordPartial("SCF_RESOURCE_LIMIT"); continue; }
    const symbols=extractSymbols(f.language, decodeUtf8Strict(f.bytes));
    const imports=extractImports(f.language, decodeUtf8Strict(f.bytes));
    const tags=parseScfAnnotations(...);
    diagnostics.push(...tags.diagnostics);
    if(tags.diagnostics.some(x=>x.blocking || x.severity==="error")) { recordRejectedSource(f); continue; }
    for(const attachment of tags.attachments) {
      const registered=lookupCurrentApprovedRef(attachment, input.registrySnapshot);
      if(!registered) { recordError("SCF_ANNOTATION_UNKNOWN"); continue; }
      facts.push(declarationFact(input.pin,f,attachment,registered));
      facts.push(...independentStaticObservations(symbols,imports,attachment,registered));
    }
    obs.push({path:f.path,blobSha:f.blobSha,symbols,imports,commentCount:tags.tags.length});
  }
  const final=sortDeduplicateByStableFactId(facts);
  return Object.freeze({
    schema:"arbor.scf.snapshot/0.1",pin:input.pin,
    facts:final,diagnostics:stableSort(diagnostics),coverage:coverageWithUnknowns(),
    digest:sha256(canonicalJson({schema,pin,registryDigest,ownerCatalogDigest,facts:final,coverage}))
  });
}
```

## Derivation rules
- `@hq:capability`: generates `unit supports capability` with `DECLARED` only. If parser, registry and source hash verified, status becomes `RESOLVED`, still not `TEST_OBSERVED`.
- Symbol existence can prove `exports` or `defines` if byte span matches actual parser; cannot independently prove algorithm correctness.
- Imports resolved through existing indexer `imports.resolved_file_id` can prove a static `depends_on` edge; **import presence != runtime executed**.
- `@hq:contract`: declared link; externally reviewed owner contract and source signature/ABI check can promote static support. Malformed/unknown contract refuses.
- `@hq:effect`: surface claim only. Actual effect authorization/receipt read only from Host.
- `@hq:action`: requires accepted Host/catalog crosswalk and exact owner; no `action.execute` generated by SCF.
- `@hq:test`: test reference declared; check file existence under pin as distinct stage, observed execution as independent receipt.
- Agent-facing prose explanations are generated from accepted template refs and qualification; never freeform mark "guaranteed" on sampled proof.
- A source file tagged with N capabilities is a **membership N-way** fact, not `N` implemented runtime handlers.
- Unknown original code: `UNANNOTATED_CANDIDATE`, keep source observation and file/symbol lineage when HVI later compares.
