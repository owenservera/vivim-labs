# Charter — prove what code means, does and says
Goal: for any tagged feature/function, give a source- and build-pinned **Proof-Carrying Capability Passport**: exact owner/feature dependencies, code links, reviewed pre/postcondition and effect claims, evidence method, tests and runtime receipt lineage, counterexamples, unknowns, truthful verbal explanation and history.

## Target outcomes (not currently delivered)
1. Low-friction file/export metadata and agent contributor discipline, including many-to-many feature membership and audited legacy waivers.
2. Additive inline v3 language and deterministic semantic compiler into source-pinned typed SC-ABI; existing v1/v2 remain compatible.
3. Separately reviewed behavioral ClaimSpec/Oracle and independent minimal Verifier Kernel; no compiler self-certification.
4. Source AST/registry witness checking, safe pure property/mutation/differential tests, scoped bounded formal checks, artifact hashes and runtime-origin owner receipts.
5. Clause-by-clause explanation truth: no unsupported universal or safety claims.
6. Existing HQ Wiki/AutoWiki, HVI temporal proof delta, read-only TierFlow inspector, agent/CI/IDE discoverability.
7. Future versioned developer SDK and staged adoption, without dependency on external donor repos.

## Non-goals
Never promise proof of arbitrary unrestricted program against arbitrary English. Sampled tests give SUPPORTED_BY_TESTS, not universal proof. Incomplete effect traces return UNKNOWN. Do not mass rewrite legacy source, build a parallel engine/DB, send real provider traffic to test a verifier, perform real HVI donor comparison without express request, ship a production installer/APK or claim Windows/Android beta approval.

## Success metric
The first credible vertical slice must detect a deliberately false source claim and explain precisely why. Later: a real pure function supported by independently authored tests, safe owner runtime witness, three-version proof delta, agent-ready workflow and an SDK consumer with recorded trust and coverage limitations.
