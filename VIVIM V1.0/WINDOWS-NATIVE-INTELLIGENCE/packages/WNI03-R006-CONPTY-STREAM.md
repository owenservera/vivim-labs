# WNI03 R006 — native ConPTY resource and bounded stream transport

Actual Rust: [conpty.rs](../rust-starter/src/conpty.rs), [stream.rs](../rust-starter/src/stream.rs). Source candidate only. Creates/owns Windows pseudoconsole and pipe pairs, validates dimensions, resizes, exposes native handle to incumbent process worker. No process launch/attach implemented. Windows requires independent input/output servicing, and older Windows ClosePseudoConsole can block; the native helper must enforce teardown protocol (stop input, drain/close output, close pseudoconsole on control thread) before drop. No automatic upgrade or privileged access. Separate stdout and stderr for ACP; never route ACP through a PTY. Lossless stream overflow poisons connection, no fake replay. Display tail signals gaps. Acknowledgement is only allowed after processing bytes; the caller must enforce consumer ownership and exact delivered cursor.
