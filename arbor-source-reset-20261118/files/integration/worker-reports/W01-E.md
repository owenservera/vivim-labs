## Pairing, Host command, and revision contracts — unchanged

**Origin/transport:** `transport.mjs` identifies Direct origins as trusted `https://*.ts.net` or dev loopback, served at `/mobile/`. Direct mode uses same-origin `/mobile/api/relay?path=...` and never silently switches to cloud. Legacy auto/cloud mode exists in retained source and must be **disabled/excluded by G for the installed ARBOR beta**.

**Single-use pairing:** `pairing-link.mjs` parses 64-lowercase-hex device token from URL fragment and redeems it via `POST /mobile/api/pair`, expecting `enrollmentRequired`, `challengeId` and a pending challenge, *not* an already paired device. Host counterpart is `apps/vivim-host/direct-phone.mjs`, `apk/pairing.mjs` and `apk/enrollment.mjs`.

**Device identity:** `device-enrollment.mjs` signs a `vivim-enrollment-v1` transcript with the `VivimDeviceKey` Android WebMessagePort bridge; `POST /mobile/api/enrollment/prove` uses scopes `relay:read`, `relay:write`, `control:read`, `control:execute`. PC approval activates the pending grant; `GET /mobile/api/enrollment/grant-status?id=...` and `POST /mobile/api/enrollment/session` issue a bounded session after device proof. Persist only grant ID/origin/user; keep session bearer in memory. Request headers: `x-vivim-grant-id` and `x-vivim-device-session`. Revocation clears the local grant.

**Command/effect boundary:** `GET /mobile/connection.json` must attest `direct=true`, `directOnly=true`, `cloudEnabled=false`. `/mobile/api/control/{catalog,language,world,lexicon,recent,plan,execute,plans/ctl-*}` remains Host-owned. Mutations require explicit plan preview and user approval; `execute` must return `vivim.control-receipt/1`, matching `planId` and `planDigest`, status `applied|failed|uncertain`. No automatic replay on lost response or uncertain send.

**View/revision boundary:** Mobile `generative-ui/host-revision-guard.mjs` refuses rollback and conflicting same-revision fingerprints. TierFlow `projectWave4PhoneAdapter` takes trusted Host observation + pairing epoch/session/device refs, policy revision, canonical document and rendered revision; it is effect-free, refuses stale/unpaired/foreign identity and does not grant approvals. TierFlow visual document != Host World != mobile shell; G must provide a typed crosswalk, not rename schemas.

**Offline shell:** `sw.js` caches only same-origin GET shell assets, never API, auth, mutation, cross-origin or paired state. Offline cached UI is not a current grant or effect authority.
