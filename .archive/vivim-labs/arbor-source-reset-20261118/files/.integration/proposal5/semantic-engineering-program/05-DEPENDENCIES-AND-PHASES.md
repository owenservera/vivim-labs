# Provisional dependency model — NOT final wave design
```text
P0 source/gate re-pin + duplicate intake
    ↓
P1 review grammar, typed ABI, trusted oracle/spec roots
    ├── P2 HQ compiler + source facts ──┐
    └── P3 independent checker ─────────┤
                                       ↓
P4 standalone falsification + bounded safe runners + artifact identity
    ├── P5 Host/Studio/TierFlow origin observations
    └── P6 claim-bound explanation + Wiki
             └── P7 optional HVI proof history
                        ↓
P8 agent/CI/IDE and staged SDK/adoption
                        ↓
P9 independent red-team + readiness decision
```
Parallelism only after contracts and exclusive scopes, no D/F same-file writes. External runtime adapters require prior Host authorization and proof scope. HVI proof adapter requires actual accepted HVI API and cannot silently use unmerged A–F. Prefer first vertical slice that refutes a known false property before expanding to product observation or public SDK.

Future phase families to design: foundation/source; semantic language; independent checker; behavioral truth; runtime truth; Wiki/HVI; developer SDK; red-team acceptance. Exact count, branches, test commands, pinned bases, Z/G gates will be established by next turn—not inferred from HVI templates.
