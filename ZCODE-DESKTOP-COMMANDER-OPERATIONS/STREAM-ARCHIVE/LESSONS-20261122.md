# Initial learning extraction — Desktop Commander history
Date: 2026-11-22. Source: 40 observed recent tool calls plus live source-file metadata. **This is an observed sample, not analysis of the entire 2,248-line JSONL/3,940-line argument log.**

## L-001 — Separate command success from test success
A `read_process_output` remote call succeeded while its contained Node tests had four failures. Model a tool-transport status, process exit, individual assertions, revision and physical acceptance as separate fields. Never count a command's successful invocation as a passed product test. **Follow-up:** make the existing test ledger correlate these statuses at an exact SHA.

## L-002 — Source/version mismatch makes regressions stale
The failing PWA suites ran against `e3f8b0d`, while subsequent ARBOR `main` commits corrected first-contact/offline/service-worker tests. Treat the earlier failures as historically observed, not evidence that current `main` is broken. **Follow-up:** re-run the named suites from refreshed, immutable source and link the actual test result.

## L-003 — Distinguish auth outcome from assertion expectation
The direct-phone suite expected HTTP 401 but observed 403. This is a precise test mismatch, not enough to conclude an unauthorized effect or production incident. **Follow-up:** inspect intended denial semantics and run both coverage and negative authorization tests at current SHA before changing behavior.

## L-004 — Generated files can trip clean-check build guards
A GPUI build command refused an unclean isolated release tree because it contained an untracked `native/gpui-desktop/Cargo.lock`. **Follow-up:** determine whether release packaging must include that lock or the guard should recognize deterministic generated files; do not blindly reset/clean a user's checkout.

## L-005 — Shell startup pollution obscures actionable failures
Repeated `Set-PSReadLineOption` errors originate from the interactive WindowsPowerShell profile in redirected/non-VT terminal sessions. **Follow-up:** prefer `pwsh -NoProfile`/non-interactive launches for validation scripts and classify that environmental noise separately from product failures.

## L-006 — Historic history is not a full stream
The remote connector reports 1,000 memory records; the actual `tool-history.jsonl` was 2,248 lines on disk at the live probe, but it is trimmed by upstream and caps large output. The rotating `claude_tool_call.log` had 3,940 lines and raw arguments, without outputs. **Follow-up:** archive both privately, then add explicit stdout/stderr tee capture in approved runners if complete output is needed.

## L-007 — Local command preflight currently blocks backup
Two `start_process` attempts were stopped before reaching the Windows command runner because the Desktop Commander blocked-command validator's PowerShell check timed out after 15 seconds. Local file metadata and selected reads still worked. **Follow-up:** diagnose/recover this preflight safely without changing security settings or running an alternative remote execution path without approval. The local capture remains BLOCKED, not PASS.
