# Atomic source topology audit

Inventory executable source and installed runtime routes, starting at Rust and following callers through Host, Studio, harness, HQKG, VLANG, VEC, TierFlow and PWA. Enumerate every actual filesystem read/write, process start, IPC command, browser effect, network connection, credential access, database mutation, context export, enrollment and grant transition. Include bypass paths, startup, recovery, worker, CLI, WebSocket, background, package and update routes. Resolve dynamic dispatch and native bridges. Trace reads as well as writes.

Each row: stable ID; source commit; file + function + line range; caller; sink; resource identity; principal derivation; trust boundary; existing enforcement; runtime reachability; intended enforcement owner; required disposition (reuse/wire/harden/isolate/retire/unresolved); risk; dependencies; negative and positive tests; evidence; status. Do not pad counts, infer execution from documentation, or record sensitive values. Record uncertainty and evidence of actual reachability. Cross-check each effect against permitted entry points and trace deny cases. Deliver a machine-readable tracker and summary with coverage limitations. This package is not the completed atomic audit.
