## Onboarding flow options (assembled from the vocabulary above)
- **A. "Wake the Base" (desktop first):** install Base → open the Vivim Chrome profile → sign in to Minds (a checklist with a live ✓ for each app) → a QR code pairs the phone → the phone takes over.
- **B. "Phone is the Self" (phone first):** install the Android app → a short Self interview → the phone asks you to set up Base → it watches Minds connect → it proposes a first Brief.
- **C. "First agent in 5 minutes":** keep the setup steps minimal, then pick one ready-made Brief (for example a morning digest), approve its first Ask, and see its first Receipt. That Receipt is the "aha" moment.

## Screen list (phone, from Claude's tabs plus the modules)
Today (Receipts feed, pending Asks) · Talk (chat that routes to Minds) · Agents (Briefs, create/grow) · Self (what Vivim knows, editable, with provenance) · Minds status (which apps are signed in and healthy) · Ask approval sheet · Receipt detail · Pairing/QR · Onboarding interview.
Desktop **Base**: pairing, Minds sign-in checklist, live run view, and a Receipt log.

## Branding directions
- **Names / treatment:** lowercase **vivim**. Its two v's suggest a mirror, or "you + your Self". The secondary line can be "we live" (Catalan).
- **Personality:** "Calm command" or "It grows with you". The aim is a steady, warm, competent partner, not a hype robot.
- **Colour / type registers (pick one):** warm minimal (off-white with one living accent) or dark premium (ink background with a bioluminescent accent). Use technical mono only for Receipts and logs.
- **Voice:** short and first-person plural ("we"). Report what was done with Receipts, and ask with Asks.
- **Logo ideas:** a "vv" mark that reads as a seedling or a pulse, and an iris that the Self "opens".

## Recommended direction
Adopt **Claude's vocabulary** (Base / Minds / Self / Brief / Receipt / Ask, and the tabs Today · Talk · Agents · Self). Use the **"we live"** brand angle with **"It grows with you"** as the positioning (Z.ai), in a **warm-minimal** register, with technical mono only for Receipts. Build onboarding as **Option C**: the first Receipt is the activation moment. Put trust in the product: Asks, Receipts, and the platform rule (Claude), plus a Trust & risks module (Z.ai).
