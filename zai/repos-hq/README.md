**Authority:** existing cross-repo SQLite/file/symbol/import index, Rust HQKG, semantic registry, catalogue adapters, context, work-order orchestration and generated documentation. No new master database, independent graph engine or roadmap writer.

## HQ is Z.ai's operating tool

Use the existing HQ CLI/index/graph/context/wiki and orchestration machinery to navigate each bounded task, select source/consumer evidence, execute safe tests and verify changes. **Improve HQ during real engineering**, then reindex so the next round inherits better coverage. Start productive work in R1, not an audit-only R0. By R4, use HQ-first scoped context for most routine cross-repo discovery, with raw source inspection only for verification, missing or stale HQ results and actual edits. Track coverage, provenance, raw reads/repeated searches and query failures per round. Do not build a separate Z.ai authority or navigation stack.
