# ✦ THE LIVING SOFTWARE UNIVERSE
### An imagination laboratory for ARBOR HQ Version Intelligence

> **Code changes. Meaning migrates. Memory should survive.**

Imagine a development system that never forgets why a capability exists, what it used to be, how it survived a rewrite, which promises changed, and where its behavior lives now. Imagine an agent you can ask *“what happened to this idea?”* and it opens a trustworthy, beautiful, living history: source, architecture, tests, lineage, decisions, uncertainty, and possible futures.

**This folder is an idea garden, not a wave, roadmap, acceptance gate or implementation order.** It is deliberately bold, sometimes impractical, sometimes poetic. None of its concepts are claimed to exist. Nothing here authorizes a live repository comparison, autonomous migration, personal-data intake, or merge.

## The transformation


## ✧ Five north-star experiences
1. **Chronicle:** a truthful, explorable time machine for a software system.
2. **Capability DNA:** an idea keeps its identity even when source files, languages, repositories or owners change.
3. **Worldlines:** “what if?” architectures appear as *clearly hypothetical* branches of possibility, never as actual source facts.
4. **The Evidence Lens:** every compelling explanation can be unfolded into exact sources, uncertainty and tests.
5. **The Quiet Companion:** the agent already knows its tools, but does nothing until the owner asks and grants access.

## Reading this material
**CURRENT** means already source-grounded or contracted elsewhere. **NEAR** is a plausible product extension. **FAR** is a research leap. **WILD** is a creative provocation. These are **not** commitments, schedule estimates or priority labels.

Keep Host as the sole effect/authorization owner, reuse Rust/HQ knowledge and TierFlow, and preserve source pinning, consent and evidence.
