## Focused independent research (reviewed 25 Nov)
- [CDP DOMSnapshot](https://chromedevtools.github.io/devtools-protocol/tot/DOMSnapshot/) and [Accessibility](https://chromedevtools.github.io/devtools-protocol/tot/Accessibility/): browser-generated state, roles and geometry, version-sensitive experimental protocol; use existing CDP actor and bounded observations, feature-detect and refuse missing evidence. Don't assume DOMSnapshot is in current source; compare cost/fidelity to existing page-agent. [W3C Accessible Name 1.1](https://www.w3.org/TR/2018/REC-accname-1.1-20181218/) clarifies computed names/labels; use browser computation rather than simplistic text matching, identity not inferred from name alone.
- [Crawljax academic source](https://repository.tudelft.nl/record/uuid%3Af7a5f58d-5d36-4105-8ac2-385c0f18cf1a): state abstraction and incremental transition inference over dynamic interfaces. Adopt bounded state fingerprints, observed transitions with pre/postcondition evidence, counterexample-driven split/merge and shortest safe typed route. Passive observations/explicitly authorized demonstrations first; do not automatically crawl/click live third-party apps or change state to explore. Use existing TemporalGraph/HQKG, not a new automaton store.
- [Ringer, OOPSLA 2016](https://www.microsoft.com/en-us/research/publication/ringer-web-automation-demonstration/): robust operation reproduction from demonstrated interactions and state conditions. Adapt into existing accepted evidence/adapter/typed recipe pipeline. Vary test input and layout to verify generalization; ambiguity and stale identity abstain; learned recipes are inert until independently authorized, no auto send.
- [WebArena, ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/hash/4410c0711e9154a7a2d26f9b3816d1ef-Abstract-Conference.html): evaluate functional final-state correctness in reproducible app environments, not action-sequence matching. Adopt methodology, NOT external browser stack; no claim of comparative performance from historical scores. Use actual first-party app state independently read back and held-out tasks. Optional comparator only approved route/budget. [WebDriver BiDi](https://www.w3.org/TR/webdriver-bidi/) standards research only (future versioned transport seam, no new browser runtime now).
- Research outputs are proposals; use actual source and evidence to decide, no blind import, no new frameworks.
