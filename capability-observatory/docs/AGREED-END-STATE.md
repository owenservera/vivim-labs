# Agreed end-state — tracked hypothesis, not asserted completion

VIVIM's consolidated product target after the **one eight-lane final Wave 5+6 campaign**, followed by **one master integration**, is:

1. TierFlow is the single canonical UI document, revision/CAS, render/typed UI command semantics and, **only after owner-approved cutover**, the one live UI publisher.
2. Existing Harness Host remains the only owner-approved action/effect/journal/receipt and device grant authority; direct app-side effect bypasses are audited and removed/delegated only after safe migration.
3. Repos HQ remains canonical source for owner/world knowledge, semantics and provenance. Devices receive only authorized bounded projections; revoked/deleted facts do not resurrect offline.
4. Existing Windows/Tauri app, existing Android APK/relay and existing Studio remain the user-facing implementations; no parallel apps, KB, command engine or editor created.
5. Oracle interprets/coordinates broadly, without issuing its own permission grants or bypassing Host owner consent. Natural language, keyboard, touch and Studio map to same typed intent and UI CAS result.
6. First-run onboarding, accessible edit and help, portable templates, preview/diff, history and UI-only undo, verified read/status/approval UX, deterministic recovery, staged single-writer migration and reversible release are tested end-to-end.
7. Zero active duplicate effect or publisher authorities is a **target**, never a seed-time finding. Inventory existing legacy gateways, catalogues, stores, renderer and migration consumers with code paths and measured runtime traces.
8. Final integration reports **separate Gate 5 and Gate 6** decisions and genuine physical PC/Android/owner-approved Host proof; missing device access remains UNRUN/BLOCKED rather than fabricated GO.
