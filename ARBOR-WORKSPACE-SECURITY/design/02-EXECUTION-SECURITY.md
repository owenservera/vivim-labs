# Execution and capability enforcement R002
## Existing authority
Host dispatcher, bounded grants and journal remain logical effect authority. Rust enforces native resource boundary. Existing native program validation remains inert and not an execution grant. TierFlow job execution and Studio/harness workers must inherit authenticated capability context. No separate orchestration engine or global unrestricted execution capability.
## Four execution classes
T0 validated declarative rendering (no ambient network/files). T1 pure typed transformation (bounded input/output and CPU/memory; no arbitrary imports). T2 isolated Wasm or platform-contained process (explicit host imports, no ambient credentials). T3 fixed registered Host effect adapter (exact authorization, audit, recovery). Generated code and imported extensions never execute in Host address space by default.
## Admission and effect protocol
Authenticate principal and device; resolve workspace/resource and program version; canonicalize and validate requested action; evaluate immutable policy and current revocations; prepare inert preview; verify exact approval/standing grant; recheck freshness at effect boundary; claim idempotency fence; perform through authorized adapter; record redacted result and evidence. Durable states: proposed -> admitted -> approved/standing-authorized -> claimed -> committed/failed/uncertain. Denied and cancelled terminal. A previously claimed uncertain network effect must reconcile rather than retry blindly. Revocation blocks new claims and cancels cancellable work; completed effects remain historical.
## Isolation and quotas
Default deny direct filesystem, socket, subprocess and clipboard access; expose typed broker operations, cap output and logs, CPU, memory, concurrency, time and external destination budgets. Resource exhaustion is contained and reported, not arbitrary product-wide caps. Sanitize environment, inherited handles and stdout. Use capability table per worker, not process-global token. Broker authenticates IPC peer and binds request to current task.
## Program distribution
Content-address manifests and executable digest, identity and version; check publisher trust and permission changes before activation. Signed means attributable, not safe. Quarantine imported packages, validate IR and dependencies, run in isolated profile, retain last known good version and revocation. No implicit upgrade authority.
## Acceptance
Permission narrowing under composition, denied self-grant, no sandbox escape in supported threat model, stale approval denied, legitimate workflow succeeds unattended, crash and retries do not duplicate effects. Actual Windows and product tests UNRUN.
