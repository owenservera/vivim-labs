## Class, specialization, instance and attempt
Class = reusable behavior contract (inputs, permitted tools, expected outputs, verification and resource limits). Specialization = runtime-generated assignment with selected context and methods. Instance = logical worker bound to a task; attempt = specific provider session/process. Model is a replaceable execution adapter. General-purpose base class is the starting baseline. Proposed behavior classes: explorer (hypothesis/alternative), investigator (evidence), experimenter (controlled execution), implementer (artifact), critic (counterexample), verifier (independent oracle), recovery (reconcile/repair), synthesizer (combine verified evidence), coordinator (delegate, schedule, resolve dependencies). These are proposed VIVIM classes, not Anthropic's documented class catalog. A worker can assume several roles over time; reviewers must be independent of authors. Coordinator can propose new class versions; Host validates scope, tools, resource caps and acceptance. No autonomous permission escalation or arbitrary process spawning.

## Lifecycle
PROPOSED -> READY -> LEASED -> STARTING -> RUNNING -> CHECKPOINTED -> RUNNING -> SUBMITTED -> VERIFYING -> VERIFIED -> COMMITTED -> CLOSED.
WAITING for dependency/message is not failure. STALLED triggers bounded status probe; FAILED confirms terminal failure; UNKNOWN triggers reconciliation before any retry. RECOVERING resumes same logical agent/transcript when supported; REASSIGNED starts fresh attempt with bounded context. Rejected submission returns to READY with reasons. Cancellation and exhausted budget stop relaunch. Use durable run_id, goal_id, task_id, class_id/version, agent_id, attempt_id, provider_session_id, parent_id, generation and effect_id. Lease generation fences stale commits. Persist event before notification; deduplicate by event_id. Separate heartbeat from useful progress. Resume from verified checkpoint; do not replay uncertain effects blindly.

## Runtime brief
Goal, task, class/version, specific objective, selected input artifacts/digests, assumptions, known failed methods, allowed tools, isolated workspace, expected artifact, deterministic oracle, negative/control test, time/token/cost limits, dependency IDs, checkpoint cadence, recipient and exit conditions. Private context per worker; communicate async via addressed durable mailbox (message ID, ack, reply correlation); share reports/artifacts not full active context. Report discoveries, uncertainty, failed approaches, evidence and next questions. Checkpoints atomic with digest and prior good version. Parent continues while workers execute. Parent may split tasks, request independent review or resume/reassign. Coordinator state is durable DAG, mailbox, leases, receipts; replaceable. Host alone admits effects; stable effect keys + reconciliation, not a promise of exactly-once external delivery.

## Experiment
Four top-level ZCode sessions; lane 04 dynamically spawns up to four child sessions; total cap 8 initially, cumulative population unbounded only within explicit run budget. Test native general-purpose brief-based specialization first. Then compare predefined role templates vs generated classes using identical tasks and models; third arm hybrid class+brief. Record class creation count, unique logical agents, attempts, peak concurrent active workers, token cost if observable, verified yield, review rejection, recovery time, duplicates and context overhead. Do not equate attempts with unique agents. Test child failure, stalled worker, conflicting results, duplicate task, coordinator death and total restart. Native baseline before adding adapter; label native/adapter/supervisor recovery distinctly. Reject fabricated support. Limit retry to 3 per fault with bounded backoff; respect explicit stop, provider limits and budgets. Only owned lab processes, simulated dependency faults, no shared configuration changes. Final oracle verifies deterministic numbered artifacts/receipts exactly once and no stale commits. 36h then 72h real elapsed time; separate downtime and productive progress. Do not publish raw transcripts or credentials to public repo.
