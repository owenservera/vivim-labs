# Independent falsification, security and acceptance

## Threats to prove absent
- Unknown engine IDs, forged component IDs, spoofed source schema/renderer installation status.
- Raw CSS, URL/javascript expressions, event attributes, HTML, source access tokens hidden in typed values.
- Prototype pollution, accessor functions, cyclic arrays/objects, enormous token graphs and alias type mismatches.
- User-supplied enum choice overrides, unregistered plugin auto-loading or unverified capsule execution.
- Multiple engines writing same final CSS field without explicit canonical ownership and deterministic precedence.
- Access to PC-private components from phone, revoked grants, stale revision, wrong actor, offline caching of secrets.
- Motion/contrast/focus/target-size safety weakened by user styling or model-generated proposals.
- Duplicate publisher, unexpected provider send, retry of uncertain effect, rollback of irreversible actions.
- ENOSPC, low-RAM, cold-start build/import explosion, stale data after crash.

## Tests and evidence levels
Source catalog and typed-value tests using actual Node24 exits, not only source-authored fixtures.
Machine catalog 37/461 uniqueness, 417 taxonomy cross-match, all dependency nodes and acyclicity.
All primitive type validators, typed DTCG subset, alias cycles, enum refusals and deterministic compiled proposal.
Adapter differential tests for existing PWA/TierFlow, denied and loss-of-information cases.
Actual Windows Host / physical paired Android Chrome tests, revocation, offline, accessibility and undo.
Synthetic p50/p95 CPU/RSS, package size/disk/energy for always-on, high/frequent, user-defined, dev/admin workloads.
Independent counterexamples, source-to-artifact pin and trust-root approval; no source-author self-verification.
