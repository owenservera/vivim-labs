# Kernel-authoritative mailbox transfer fence

Baseline 26deab535cb57d48e1b2b27a495e3e10a965e5a0. R08 source hardening. The mailbox now commits AuthorizeMailboxTake against the durable handoff in the kernel before it can return input and single-attempt send authority. This revalidates binding version, input pin, task/goal/lease status and deadline in the same transaction. A record retains the manifest/packet pin and authorization time. The same request ID returns only reconciliation authority on replay; another ID cannot reauthorize the same handoff. If the kernel commit succeeds but the local taken marker is missing, the bridge cannot obtain a second send permission; resolution requires explicit trusted observation. Existing direct host/signed adapter claim API remains for synchronous adapters; a trusted host must choose exactly one transport. No real provider dispatch or test execution performed. Windows crash durability and real adapter behavior remain unqualified.
