### RCK-F016 — A revoked visit can NEVER leave the Rust graph (material correctness gap)
- **Date:** 2026-11-11. **Category:** risk / correctness. **State:** source-verified by the parent; implementation admitted to the master-integration workflow.
- **Statement:** The Rust ingest path accepts ONLY `type == "visit.observed"` and rejects every other event type, so a revocation can never enter the Rust graph.
