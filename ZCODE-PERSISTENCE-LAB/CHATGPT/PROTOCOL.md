## 2. Controlled comparison

Record provider substitutions and scheduling contention. Randomize lane launch order across repeats using recorded seed, align injection by logical progress milestone, use at least three repeats for initial comparison, report distributions and censored failures. Independent controller records evidence but does not provide hidden recovery hints. Each lane can use only its declared persistence authority. Separate native baseline from adapter/supervisor capabilities.

Count learning cost against same budget; warm trials may invoke deterministic procedures without inference.

## 3. Workload and fault treatment
Common synthetic task: construct a deterministic sequence of numbered artifacts with exact expected content and SHA256 receipts, then adapt to changed inputs. Independent oracle holds expected outputs and rejects duplicates, stale lease generations, missing entries and invalid digests. Use a recurring task family (cold, repeated identical operation, related variant, novel holdout) to measure amortization; use multiple seeds and keep holdout results out of recovery context. Benchmark trivial tasks as well as compositional tasks with independent subtasks and dependency changes.
All 24 original fault scenarios are shared treatments. For every injection record lane/run, logical milestone, owned target, failure evidence, recovery action and provenance, recovery latency, state before/after, oracle outcome. Native baseline then minimal repair/replay within allowed architecture. Combined total restart: terminate all owned sessions and coordinator, restart controller, see which lanes continue without manual hints. Unsupported treatments remain explicit. Simulated outages only, no global networking/config changes. Require explicit finite budget and stop control; stop on cancellation, authorization denial or exhausted budgets.
