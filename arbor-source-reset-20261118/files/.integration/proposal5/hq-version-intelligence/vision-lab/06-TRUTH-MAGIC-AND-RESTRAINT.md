# 06 — The truth is part of the beauty
The danger of a gorgeous “software universe” is that it can make guesses feel more convincing than plain text. The more visionary the presentation, the more rigorous the epistemics must become.

## Seven visible states, never conflated
| State | What may be said | What must not be implied |
|---|---|---|
| **Pinned source observed** | These bytes/paths existed at this commit | Same behavior survived |
| **Exact identity evidence** | Same verified blob / owner-approved identity | All semantics identical |
| **Changed contract** | This typed interface changed | Runtime definitely broke |
| **Test source present** | A relevant test was found | Test executed or passed |
| **Test executed** | Specific runner/command/exit was observed | Every platform accepted |
| **Hypothesis** | A possible relation or worldline | Observed source fact |
| **Unknown / inaccessible** | Evidence unavailable or uninspected | Capability absent |

## Anti-magic checklist
- No background comparison, ingestion, indexing of new source, price-like monitoring or surprise audit from merely opening the lab.
- No use of owner/personal corpora without explicit consent and purpose-limited scope.
- No execution of donor source, provider browser automation or inferred privileges.
- No authority escalation from a generated semantic similarity score.
- No green “safe” ribbon when only static source/tests were inspected.
- No removing a capability based on an uninspected missing path.
- No implicit replacement of Rust HQKG, Host effect writer, permission store, Studio sender, or TierFlow renderer.
- No real repo comparisons in the current wave; invented fixtures only.

## Three levels of consent
1. **Ask** — a person requests a comparison at a later date.
2. **Scope** — the person grants specific source roots/repos/revisions for this action, and Host enforces live authorization per read.
3. **Act** — source reads and resulting analysis execute within limits; any future write, migration, refactor or export is a *separate* explicit effect with receipts.

## A famous answer HQ should learn
“I can tell you where the old code went, but I cannot yet prove the behavior survived.”

That's not a failure of intelligence. It is the beginning of trust.

## One ethical paradox
A flawless visualization of incomplete evidence can be more misleading than a flawed table. Every animation, icon and transition must reveal, not conceal, how much is known.

The most beautiful feature may turn out to be a **visible, honest hole in the map**.
