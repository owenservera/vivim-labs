# Dynamic subagent classes and lifecycle — R002
Status: proposed, not run. Sources: https://www.anthropic.com/research/riemann-zeta ; https://assets.claude.com/d7f3ecf1d01392d887f8bc974ca187e2a121b1ed.pdf ; https://assets.claude.com/8a0d1add3c637b858a9a181e98c40e9548c3f44f.pdf . Anthropic reported ~60 cumulative Claude subagents, not 60 predefined classes or confirmed simultaneous workers. Coordinator generated briefs for isolated instances with selected earlier reports, targets and controls. Contribution classes were retrospective: 30 unsuccessful explorations, 13 supporting ideas, 13 validators, 2 principal discoveries, 2 writers. Do not conflate contribution with initial role.

## Class, specialization, instance and attempt
Canonical design: OWNER-DESIGN-R002.md. One general-purpose base class, composable operators Observe, Discover, Reason, Decompose, Plan, Construct, Execute, Experiment, Challenge, Verify, Repair, Synthesize, Optimize, Delegate, Learn. A class is a versioned composition of operators, constraints, capabilities, expected outputs and verification, not a fixed personality. Runtime specialization = task plus selected context; logical agent = durable identity; incarnation = provider session/process. New logical agent receives an isolated new directory; incarnation receives a new attempt directory within existing logical identity. Filesystem projections are not canonical storage. Class promotion/learning is exclusive to lane 04; other lanes use the same static base operators. Independent verification must not be performed by the artifact author. Host validates scope and budget; no permission escalation.

## Lifecycle
PROPOSED -> READY -> LEASED -> STARTING -> RUNNING -> CHECKPOINTED -> RUNNING -> SUBMITTED -> VERIFYING -> VERIFIED -> COMMITTED -> CLOSED.
WAITING for dependency/message is not failure. STALLED triggers bounded status probe; FAILED confirms terminal failure; UNKNOWN triggers reconciliation before any retry. RECOVERING resumes same logical agent/transcript when supported; REASSIGNED starts fresh attempt with bounded context. Rejected submission returns to READY with reasons. Cancellation and exhausted budget stop relaunch. Use durable run_id, goal_id, task_id, class_id/version, agent_id, attempt_id, provider_session_id, parent_id, generation and effect_id. Lease generation fences stale commits. Persist event before notification; deduplicate by event_id. Separate heartbeat from useful progress. Resume from verified checkpoint; do not replay uncertain effects blindly.

## Runtime brief
Goal, task, class/version, specific objective, selected input artifacts/digests, assumptions, known failed methods, allowed tools, isolated workspace, expected artifact, deterministic oracle, negative/control test, time/token/cost limits, dependency IDs, checkpoint cadence, recipient and exit conditions. Private context per worker; communicate async via addressed durable mailbox (message ID, ack, reply correlation); share reports/artifacts not full active context. Report discoveries, uncertainty, failed approaches, evidence and next questions. Checkpoints atomic with digest and prior good version. Parent continues while workers execute. Parent may split tasks, request independent review or resume/reassign. Coordinator state is durable DAG, mailbox, leases, receipts; replaceable. Host alone admits effects; stable effect keys + reconciliation, not a promise of exactly-once external delivery.

## Experiment
Four equal top-level ZCode environments: 01 persistent session, 02 persistent agent, 03 persistent goal, 04 persistent intelligence. Every lane gets the same subagent opportunity (one concurrent child each initially, eight total slots); cumulative agent count is separate from peak concurrency. Each lane is subject to its authority boundary in experiment.json. Lane 01 uses native session recovery; lane 02 retains logical identity and checkpoints across incarnations; lane 03 replaces entire agents and coordinator from durable goal/task/evidence; lane 04 additionally assimilates verified behavior into versioned reusable capabilities. Native baseline before added adapters; label recovery provenance. Test the common 24 faults in every environment, including child failure, stalled worker, conflicting results, duplicate task, coordinator death and total restart. No cross-lane learning. Measure unique agents, incarnations, verified yield, token/cost if observed, assimilation and reuse cost. Retry budget three per fault with bounded backoff, stop on cancellation, denial or budget exhaustion. Only owned lab processes, simulated dependency faults and reviewed sanitized evidence. See PROTOCOL.md; no live execution claimed.
