# 03 — The idea starfield
**60 sparks.** These are intentionally unordered. Some are almost practical; some are deliciously speculative. No hidden priority, schedule, implementation order or comparison run. `NEAR / FAR / WILD` describe imaginative distance, not an approved roadmap.

## Time, memory and lineage
- **VL-TIME-01 · Temporal palimpsest** — Overlay multiple pinned eras of a system as translucent architectural layers. *[NEAR]*
- **VL-TIME-02 · Commit constellations** — See commits cluster by the capabilities they moved, not just by calendar or file. *[NEAR]*
- **VL-TIME-03 · Source memory capsule** — Open the exact evidence and assumptions that existed when an old decision was made. *[NEAR]*
- **VL-TIME-04 · First appearance detector** — Trace a concept's earliest *evidenced* appearance across approved sources. *[FAR]*
- **VL-TIME-05 · Capability half-life** — Explore how long a capability's contracts stay stable after successive rewrites. *[FAR]*
- **VL-TIME-06 · History compression** — Summarize years of evolution into a handful of verifiable turning points. *[FAR]*
- **VL-TIME-07 · Evolution filmstrip** — Scrub a reversible, source-pinned visual story of architectural change. *[NEAR]*
- **VL-TIME-08 · The missing era** — Show honest blank intervals where no authorized source snapshot is available. *[NEAR]*
- **VL-TIME-09 · Semantic fossils** — Recognize retired names and comments that still explain present-day structure. *[FAR]*
- **VL-TIME-10 · Memory breadcrumbs** — Let a viewer leave a private, provenance-linked note for a future exploration. *[NEAR]*

## Identity, behavior and capability DNA
- **VL-DNA-01 · Capability genome** — Describe each capability by inputs, outputs, effects, owner, invariants and evidence. *[NEAR]*
- **VL-DNA-02 · Language-crossing lineage** — Trace a behavior's plausible migration from JS into Rust without equating bytes. *[FAR]*
- **VL-DNA-03 · Split-and-fuse ancestry** — Draw many-to-many successor lines when one module becomes several, or vice versa. *[NEAR]*
- **VL-DNA-04 · Name-change immunity** — Preserve identity when a symbol or package gets renamed. *[NEAR]*
- **VL-DNA-05 · Executable promise cards** — Turn contracts into understandable promises, each linked to tests and receipts. *[FAR]*
- **VL-DNA-06 · Compatibility fingerprint** — Compare public behavior shapes independently of implementation language. *[FAR]*
- **VL-DNA-07 · Intent genealogy** — Trace an idea through design, proof, implementation, production and retirement. *[FAR]*
- **VL-DNA-08 · Authority DNA** — Attach the effect owner and permission model to every capability's identity. *[NEAR]*
- **VL-DNA-09 · Ghost capability detector** — Identify code that appears present but has no proven reachable entrypoint. *[NEAR]*
- **VL-DNA-10 · The uncertainty gene** — Treat ambiguity itself as a tracked, explainable feature of identity lineage. *[NEAR]*

## Visual wonder and interface poetry
- **VL-VIS-01 · Architecture terrarium** — A quiet, living view in which dependencies grow, branch and fade across versions. *[WILD]*
- **VL-VIS-02 · Evidence x-ray** — Switch layers between copied source, typed contracts, tests, effects and runtime receipts. *[NEAR]*
- **VL-VIS-03 · Confidence halos** — Use clearly labeled visual halos for certainty, with accessible text equivalents. *[NEAR]*
- **VL-VIS-04 · Pathfinder ribbons** — Follow one capability across repositories, languages and dates like a metro route. *[NEAR]*
- **VL-VIS-05 · Change choreography** — Animate architectural deltas as a controlled sequence, not overwhelming particle noise. *[FAR]*
- **VL-VIS-06 · The provenance microscope** — Zoom smoothly from an executive explanation down to exact blob and line. *[NEAR]*
- **VL-VIS-07 · The blank canvas** — Make an unrun comparison look intentionally beautiful, not suspiciously broken. *[NEAR]*
- **VL-VIS-08 · Pocket-to-desktop continuity** — Same pinned query and evidence story on phone and Windows through TierFlow. *[NEAR]*
- **VL-VIS-09 · Architecture weather map** — Display where evidence is thin or contracts drift, without fake forecasts. *[FAR]*
- **VL-VIS-10 · A thousand repos, one map** — Progressive multi-resolution visualization of approved source universes. *[WILD]*

## Counterfactual design and foresight
- **VL-FUT-01 · Worldline explorer** — Examine alternative architecture hypotheses beside observed history. *[FAR]*
- **VL-FUT-02 · What-if a port never happened?** — Reason about possible dependency differences without executing changes. *[FAR]*
- **VL-FUT-03 · Future compatibility sketch** — Project likely contract collisions from proposed signatures, visibly hypothetical. *[FAR]*
- **VL-FUT-04 · Evolution pressure map** — Show which interfaces carry the greatest future coordination burden. *[FAR]*
- **VL-FUT-05 · Migration gravity** — Reveal features that repeatedly accumulate duplicate implementations. *[FAR]*
- **VL-FUT-06 · Architecture trade-off gallery** — Compare imagined configurations by explicit assumptions, never invented results. *[NEAR]*
- **VL-FUT-07 · Proof debt forecast** — Explore where changes would require new validation to remain trustworthy. *[FAR]*
- **VL-FUT-08 · Reversible proposal sculpture** — Compose a visual change hypothesis before deciding whether to write a spec. *[WILD]*
- **VL-FUT-09 · Constraint-aware ideation** — A future assistant can brainstorm within Host/TierFlow/Rust authority invariants. *[NEAR]*
- **VL-FUT-10 · The alternative's cost** — Show unknown cost surfaces before anyone pretends to estimate performance. *[NEAR]*

## Native agency and human partnership
- **VL-AGENT-01 · Ask without teaching** — Agent discovers installed comparison tools and asks only for missing authorization. *[NEAR]*
- **VL-AGENT-02 · Question-to-evidence compiler** — Translate a human question into pinned source scope and explainable checks. *[NEAR]*
- **VL-AGENT-03 · Evidence appetite control** — Offer low/medium/deep bounded exploration levels at user invocation. *[NEAR]*
- **VL-AGENT-04 · Why-not answers** — Explain why HQ refused access or couldn't prove equivalence, without blaming user. *[NEAR]*
- **VL-AGENT-05 · Human verdict handshake** — Let owners approve equivalence decisions with durable, auditable provenance. *[NEAR]*
- **VL-AGENT-06 · Socratic code archaeologist** — Ask one good clarifying question only when ambiguity changes the result. *[FAR]*
- **VL-AGENT-07 · Personal research lens** — Remember a user's preferred explanation depth without retaining secret source data. *[FAR]*
- **VL-AGENT-08 · Portable explanation bundle** — Export a self-contained redacted evidence narrative and its source pins. *[NEAR]*
- **VL-AGENT-09 · The one-minute museum tour** — An agent can introduce a subsystem's evolution in sixty seconds. *[FAR]*
- **VL-AGENT-10 · Quiet readiness** — The system advertises it *could* compare; it does not prefetch or monitor by default. *[NEAR]*

## Computation, verification and planetary scale
- **VL-SYS-01 · Differential provenance engine** — Track evidence lineage through each transformation, adapter and report. *[NEAR]*
- **VL-SYS-02 · Reproducibility crystal** — A report can be regenerated from immutable manifests without donor checkout. *[NEAR]*
- **VL-SYS-03 · Typed semantic ABI atlas** — View interface compatibility across native and browser boundaries. *[FAR]*
- **VL-SYS-04 · Incremental lineage cache** — Reuse valid immutable comparison sub-results while respecting authorization. *[FAR]*
- **VL-SYS-05 · Constrained proof synthesizer** — Suggest tests that would close an evidence gap; never label them executed. *[FAR]*
- **VL-SYS-06 · Negative-space inventory** — Represent what is inaccessible, excluded or unobserved as carefully as what's found. *[NEAR]*
- **VL-SYS-07 · Evidence conflict detector** — Surface contradictory schema, test and author claims instead of choosing silently. *[NEAR]*
- **VL-SYS-08 · Computational carbon lens** — Show actual measured cost of an analysis when measurements exist. *[FAR]*
- **VL-SYS-09 · Epistemic debugger** — Expose which source claim or adapter made an explanation too confident. *[FAR]*
- **VL-SYS-10 · Universal software passport** — An exportable, privacy-scoped capability identity portable across organizations. *[WILD]*
## Wild combinations
- **Temporal palimpsest × Capability genome × Evidence x-ray** = open a feature, drag time, watch its implementation change, and inspect why each continuity claim is justified.
- **Question-to-evidence compiler × Negative-space inventory** = ask an ordinary question and see not just findings but exactly what the tool could **not** know.
- **Worldline explorer × Proof debt forecast** = imagine a change, see what would need verification, without writing or running it.
- **Architecture terrarium × Pocket continuity** = one expressive living view from workstation to phone, derived from the same typed evidence.
- **Universal passport × Human verdict handshake** = a capability history that travels between teams without exporting their private source.
