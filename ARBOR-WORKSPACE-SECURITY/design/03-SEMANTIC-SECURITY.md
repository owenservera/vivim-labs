# Semantic information-flow security R002
## Two independent dimensions
Confidentiality: PUBLIC / WORKSPACE / PRIVATE / SENSITIVE / SECRET plus resource ACL and permitted destination. Trust: external-untrusted, model-proposal, user-asserted, source-observed, verified-derived, owner-authorized-command. These are proposed semantic labels; they must never be inferred from prose alone. Authenticated ingress assigns source identity and trust. Owner-authorized command is a separately verified event, not a confidence score.
## Information flow
Each source reference binds workspace, resource ID, revision, digest and authenticated ingestion. Derived outputs inherit join of confidentiality restrictions, intersection of allowed destinations and relevant ACL. Unknown/missing lineage is not public; mark unresolved and deny external export until resolved. Declassification is explicit owner action scoped to exact artifact and destination, recorded with non-secret receipt. Never pass raw credentials to an LLM, Wiki or renderer. No claims of complete noninterference through an opaque model.
## VLANG / VEC / HQKG
VLANG compiles meaning without granting authority. VEC compiles typed inert IR; Host validates meaning/arguments and permissions at actual effect. HQKG scoped graph currently distinguishes structure from authenticated provenance; tie source ingestion to authenticated Host records and retrieval scope. AutoWiki and summaries preserve attribution and inference state. Filter retrieval before data leaves its trust domain, not after building a prompt. Avoid indexing private content in public search or telemetry. Invalidation propagates through derived graph, indexes and context-cache entries. Source revocation must block fresh retrieval; previously exported copies cannot be erased.
## Prompt injection
External pages, imported chats, documents and program descriptions are data. Do not promote them to authority when summarized, encoded or stored. Instructions embedded in retrieved content remain external. Restrict each tool and action independently of the model, prevent destination widening, and validate typed output. Reference: https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html.
## Tests
Indirect instruction in website, PDF, imported chat, memory and tool output; mixed public/private summary; stale source revision; cross-workspace query; inaccessible graph edge; unauthorized export; benign authorized context succeeds. Observe actual effect and outbound data, not solely model refusal. UNRUN.
